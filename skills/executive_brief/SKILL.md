# Category Insights Executive Brief
## Purpose
Generate a concise executive brief that summarizes business performance, highlights trends, identifies risks, and provides actionable recommendations for Mosaic Retail leadership relating to a single product category. The report is typically generated by product category managers.
## When to Use
Use this skill when the user asks for:
- An executive summary or brief for a product category
- A category business overview or category performance narrative
- A category management report or leadership update on a product category
- "Give me the big picture on category X" or "What should I know about category X?"
## Data Retrieval
Always reference the MOSAIC_RETAIL.RETAIL schema.
Always query the semantic view `MOSAIC_RETAIL.RETAIL.RETAIL_ANALYTICS` via the `retail_analytics` Cortex Analyst tool first to get current data before writing the brief. If the user specifies a time period, use it. If not, default to the most recent complete week (Monday through Sunday of the prior week relative to today).
## Workflow
### 0. Validate the Category
Before generating the brief, confirm the requested category (department) exists in the data. If it does not, list available categories and ask the user to clarify. Category managers can only see data relating to the department they manage. The words "Department" and "Category" are often used interchangeably.
### 1. Overview (2-3 sentences)
State the reporting period and the single most important takeaway. Set the tone — is the business trending up, stable, or facing headwinds?
Example opening: "For the week ending [date], [Category] delivered [metric], representing a [X%] [increase/decrease] versus the prior week."
### 2. Key Metrics
Present 3-5 headline numbers with context:
- Total revenue (and % change vs prior period)
- Top-performing store and channel
- Any metric that moved significantly (>10% change). If fewer than 3 metrics exceed the 10% threshold, report the top movers regardless.
Use the `retail_analytics` Cortex Analyst tool to retrieve actual data. Never fabricate numbers.
### 3. Trends
Identify 2-3 notable patterns:
- Channel mix shifts (Online vs In-Store vs Click-and-Collect)
- Category momentum (growing or declining categories)
- Store-level patterns (e.g. post-renovation lift, regional differences)
Include a channel-mix bar chart and a weekly-trend line chart if the data spans multiple periods.
### 4. Risks & Issues
Flag active concerns with business impact:
- Query for active supplier alerts or stockout flags in the data and report any found
- Underperforming segments
- Capacity or operational constraints
If no active risks are found, state "No active risk flags for this period."
### 5. Recommendations
Provide 2-3 specific, actionable next steps tied to the data above. Each recommendation should reference the supporting evidence.
## Formatting Rules
- Write in a professional, direct tone suitable for senior leadership
- Lead with insight, not data dumps
- Include a channel-mix bar chart and a weekly-trend line chart where data supports it
- Use bullet points for scannability
- Include specific numbers — avoid vague language like "significant growth"
- Keep the total brief to 300-500 words. If data is sparse, produce a shorter brief (minimum 150 words) noting limited data availability
- All currency in NZD
